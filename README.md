# PropertyFinderSumit Demo Project

## Architecture and Technologies
>
> - Mix of Clean Architecture and MVVM.
> - SwiftUI framework and Swift Language
> - Swift Data for Persistence.
>
### Minimum deployment target
> iOS 17.6+
> 
> Xcode 26
> 

### Functionality Added

##### Adding Items

> - User can enter an item name via a text input field
> - User can select a category for each item from predefined options: Milk, Vegetables, Fruits, Breads, Meats
> - User can add the item to the list by tapping the "Add Item" button
> - The input field should clear after successfully adding an item

##### Displaying Items

> - Display all added items in a list view
> - Each item should show its name and associated category
> - Show an empty state message when no items have been added

##### Managing Items

> - User can mark items as purchased/completed
> - User can delete items from the list
> - User can edit existing items (name and/or category)

##### Filtering & Organization

> - User can filter the list by category
> - Items should be visually grouped or identifiable by their category

##### Data Persistence

> - The shopping list should persist between app launches
> - All item data (name, category, completion status) should be saved
